# Super PI Agent 2.0.0

## 全新品牌

- 产品更名为 Super PI Agent，应用内自称 PI；桌面名称、图标、通知图标、欢迎动画与空状态统一为新的机器人形象。
- 字标改为 PI.，引导页、抽屉与悬浮球同步更新。

## 新包名

- 应用包名改为 `io.github.whywood.superpi`，深链改为 `superpi://`，小程序桥改为 `SuperPINative`。
- 插件 ID、插件 SDK 与 Maven 坐标改用新的 SuperPI 命名；旧版插件与旧版 App 不再互相兼容。
- 这是一个独立的新应用：不能覆盖升级旧版，旧版会话与设置不会自动迁移；需要时请先在旧版导出会话。

## 默认主题

- 新增 PI 黑白主题并设为默认：浅色与深色两套完整配色，跟随系统自动切换；按钮、选中态与人机对话气泡以黑白为主，状态色只承担语义。
- 原有的跟随系统、经典蓝、Santorini 与 Oceanic 保留在设置里，可以随时切回。

## 仓库与市场

- 代码仓库、插件市场与 Maven 仓库更名为 SuperPI-*；市场索引与 SDK 依赖地址同步更新。
