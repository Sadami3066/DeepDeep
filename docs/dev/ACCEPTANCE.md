## CHAT · 聊天运行、失败与重试（10）

### ACC-CHAT-01 · 长任务过程实时可见
- 旧编号：旧 #1
- 前置：已配置可用厂商 Key；网络正常；App 已进入聊天页。
- 操作：发送需要连续 3 次 `bash sleep 5`（或 ≥3 次工具调用）的请求；在 2/6/12 秒时各看一次屏幕。
- 可见判据：
  - 通过：2/6/12 秒均能看到运行中状态、思考/工具行与递增的运行耗时；结束后过程可折叠，最终回答完整显示在过程之外。
  - 失败：任一时刻运行状态或耗时缺失；结束后过程不可折叠或最终回答缺失。

### ACC-CHAT-02 · 长命令停止
- 旧编号：旧 #4
- 前置：已配置可用厂商 Key；网络正常；App 已进入聊天页。
- 操作：发送包含 `sleep 60` 的命令并等工具开始执行；点停止按钮。
- 可见判据：
  - 通过：状态区出现「已停止」，该工具行标记失败/停止，`ps` 或会话里看不到对应 Proot 进程。
  - 失败：仍在运行；无停止提示；工具行仍显示运行中。

### ACC-CHAT-03 · 失败可见与重试
- 旧编号：旧 #49
- 前置：已配置可用厂商 Key；网络正常；App 已进入聊天页。
- 操作：断网或用无效 API Key 发送；恢复后点「重试」；杀进程重开查看历史。
- 可见判据：
  - 通过：该轮显示本地化错误（如「余额不足」「Invalid or expired API key」）与「重试」；恢复后重试成功；重启后失败轮仍在。
  - 失败：静默失败；无错误文案；重试无效；历史丢失。

### ACC-CHAT-04 · 重新生成（手动重试）
- 旧编号：旧 #54
- 前置：已配置可用厂商 Key；网络正常；App 已进入聊天页。
- 操作：关闭自动重试，断网发送得到失败轮；恢复网络点「重试」。
- 可见判据：
  - 通过：失败气泡与错误行保持不动；按钮变加载圈后流式生成，无重影；用户消息不重复；JSONL 里失败回合被 context edit 移除。
  - 失败：失败轮被清空；用户消息重复；重试无响应。

### ACC-CHAT-05 · 自动重试
- 旧编号：旧 #55
- 前置：已配置可用厂商 Key；网络正常；App 已进入聊天页。

- 可见判据：
  - 通过：状态行显示「自动重试 n/5」并自动重试，恢复后自动成功；超时类错误不自动重试。
  - 失败：不显示重试计数；不自动重试；恢复后仍失败。

### ACC-CHAT-06 · 自动重试上限

  - 失败：无限重试；失败轮被清空。

### ACC-CHAT-07 · 失败文案本地化

### ACC-CHAT-08 · 手动压缩

### ACC-CHAT-09 · 停止自动重试
- 旧编号：旧 #136

  - 通过：倒计时消失、之后不再自动重试、UI 回到可输入；再次发送正常。
  - 失败：仍在重试；UI 卡住；无法再发送。

### ACC-CHAT-10 · 自动重试状态行

  - 失败：不显示；只闪一下；停止后仍重试。
