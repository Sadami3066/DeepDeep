# Super PI Agent 2.0.1

## 抽屉与聊天

- 抽屉顶部换成新的品牌头：白色圆底上的挥手 PI，加上「Super PI.」标题。
- 新对话按钮改为 PI 主色实心样式，浅色黑底白字、深色白底黑字。
- 聊天顶部的当前 Bot 可以直接点开它的设置。
- 新建 Bot 不再自动展开抽屉里的 Bot 会话；点 Bot 才展开。
- 新建 Bot 或更换头像时，可以先拖动、缩放，把图片裁成合适的头像。

## 悬浮球

- 悬浮球不再显示「PI.」文字，改为按状态显示 PI 的表情：空闲、运行中、休眠、等待回答、完成、失败。
- 深色主题下仍然是白色圆底，黑机器人清晰可见。

## 字体与主题

- 默认字体改为 Fredoka。
- 修复打开悬浮窗后部分文字突然变成系统字体的问题；切换字体后，主界面、悬浮窗与插件页会一起更新。
- 主题设置移除重复的「跟随系统」；PI 主题本身会跟随系统深浅色，旧选择自动落到 PI。

## 资源

- 新的高清图标、欢迎页吉祥物与过程动画上线，旧的低清机器人素材与欢迎 GIF 移除。
