# 功能与边界

产品层说明：什么能用、怎么用、边界在哪。构建与安装见 [../README.md](../README.md)，不可推翻的设计取舍见 [DECISIONS.md](DECISIONS.md)。

## 对话

- Claude 风格布局：右侧浅色用户气泡、全宽 assistant；输入区是浮在对话之上的白色 28dp 圆角卡片（柔和投影、无整宽底板），对话从卡片背后滚过；上下文 token 环在卡片右上角；回车换行，只按发送按钮发送
- 过程按 DSH 思路展示：运行中展开、行首显示转圈与实时耗时，工具/思考行默认收起，结束后自动折叠只留最终回复并显示总耗时（聊天设置可关）
- 对话不自动跟底：生成过程中滚动位置不动，由你自己往下看；发送消息或切换会话才回到底部/上次位置，向上翻后右下角出现「回到底部」按钮
- 工具调用与中间文本按事件顺序进入过程；历史会话按一个用户回合聚合
- Markdown：标题、段落、引用条、有序/无序/任务列表、表格、带语言标签与复制按钮的代码块
- 42 家 Provider，API Key / OAuth 登录（Anthropic、OpenAI、GitHub Copilot、Codex、xAI、OpenRouter、Kimi、Meta、Radius…）；模型与思考档**按会话独立**，只列已配置的厂商
- 会话历史、置顶、归档、重命名、删除；抽屉按工作区分组（每区默认显示最近 5 条）
- 运行状态对账：后台唤醒、锁屏断网重试结束后不会停在「运行中」；思考计时本地化（`1 小时 2 分 3 秒`）
- 模型提问最多等你 10 分钟，超时会收起问题卡、按普通工具结果继续
- 正文字号 85%–140%（聊天设置，只缩放消息正文/代码/表格/过程）
- 字体：英文 Lora（默认）/ Manrope，中文走系统字体
- 输入区右上角上下文 token 环 + 会话统计 sheet（占用/窗口、输入/输出/缓存、费用）
- 选择文本后复制/全选/引用/朗读；引用以 blockquote 前缀随消息发出
- 附件：聊天与系统助手浮层的 + 号提供图片、文件和拍照入口，最多 20 个、单文件上限 1 GB；拍照在紧凑的 4:3 相机小窗内完成（黑色无白壳，取景区下方是快门/关闭/切换镜头，关闭 sheet 即解绑相机），不再跳转系统相机；发送给模型的附件路径为真实绝对路径，历史附件仍可显示。图片处理期间切换会话仍发送到原会话，停止会取消尚未完成的图片发送准备。
- 交付卡片：模型调 `present` 后按顺序显示图片（内联，GIF 与动画 WebP 会动）、视频（封面卡，点开播放）、HTML（内联 WebView）、文件卡、创意入口卡；浮层内同样可内联打开或预览（文件与 md 就地预览）
- 右上角「…」→「目录文件」进入工作区文件页面（可逐级返回，标题在顶栏）；文件按类型显示图标，支持图片（GIF/动画 WebP 原生播放）、Markdown、HTML、源码与视频预览，Markdown/HTML 在预览界面顶栏用眼睛/R 图标切换预览与源码；顶栏下载图标可把当前文件存到公共「下载」目录（任何格式），图片预览长按弹出底部操作单（保存到「下载」/分享，右上角 X 或点空白关闭），不支持的格式可调用外部应用。

## `/` 命令

只有整行是一个命令才执行；命令不进模型上下文。

| 命令 | 参数 | 行为 |
|---|---|---|
| `/compact` | 无（后面文字忽略） | 立即压缩较早历史，显示压缩前后 token；运行中/无可压缩内容时有提示 |
| `/goal` | `<目标文本>` / `pause` / `resume` / `clear` | 文本直接创建目标；pause/resume/clear 操作当前目标 |
| `/skill:<name>` | `[需求]` | 强制加载任意已启用技能，正文以 `<skill>` 块进入本轮；未知技能保留输入并提示 |

输入 `/` 会展开面板（只补全不执行），App 命令在上、已启用技能在下；未知命令不发送。

## 动手

- Alpine/proot 里的 `bash`：无 root 用户空间，**不是安全沙箱**
- 权限分三档（设置 → 权限）：普通档只有 `bash`；无线调试（ADB）/Root 档按实际可用后端注册工具——ADB 守护可用时 `adb_shell`（App 内嵌守护，uid 2000），Root 可用时 `root_shell`；按当前配置与实际可用后端注册。两个 shell 工具默认 15s、上限 120s，与 `bash` 共用输出格式（截断提示 + 退出码）；不限制前台与轮次来源，后台、定时、目标续跑与工坊 Agent 都能用。
- 无线调试首次设置（无需安装其他 App）：开发者选项打开「无线调试」→ 权限页点「配对无线调试」→ 在系统「使用配对码配对设备」页面看到 6 位码 → 下拉通知并展开（部分系统需长按）输入配对码；配对成功后自动点火守护进程。重启后无线调试会关闭，重新打开后在权限页点「连接并启动守护进程」即可，无需重新配对。
- 后台任务：`job_start`、`job_output`、`job_list`、`job_kill`；`output` 返回增量与状态行；运行中数量显示在聊天顶栏右侧（与上下文占用、定时任务、更多并列）
- 定时任务：`schedule_create`、`schedule_list`、`schedule_update`、`schedule_delete`；五段 cron（英文名、`*`/`/`/`,`/`-`、范围含 1827 天），绑定会话，到点投递回原对话；错过时下次打开补投一次；Service 被杀后不保证投递
- 目标（goal）：`get_goal`、`create_goal`、`update_goal(action=edit|pause|resume|complete|blocked)`；自动续跑，轮数上限来自设置或显式参数；**只在进程内有效**，重启清空
- 交付：`present` 文件/图片/视频/HTML/创意；文件必须存在、可读且是普通文件，普通文本回复无需交付卡
- 文件工具必须显式传绝对路径，工作区只提醒默认位置；不接受相对路径、`~` 或省略路径。截图、下载、工坊与日志返回一个可在文件工具、Linux 和交付间直接复用的绝对路径；正文、HTML 引用、glob 和任意命令不改写。
- 普通 Linux 命令显示尾部最多 2000 行/50 KiB，超出后返回流式保存的完整日志路径；ADB/Root 上游截断时明确标为不完整。超时保留已产生输出，取消向上传播，不自动重跑。

## 悬浮窗

- 设置 → 悬浮窗 开启后，小鲸鱼在 App、系统助手浮层与其他应用上一律显示
- 运行中打转、有提问或交付时招手，右上角数字是待处理数量。点气泡打开运行面板（运行中会话、待处理提问/交付），用面板右上角 X 收起；长按开关虚拟屏小预览，预览可与卡片或面板同屏，顺序为气泡 → 卡片/面板 → 预览（预览在远离气泡的一侧，空间不足时自动缩小或退回只显示预览）
- 运行面板里可勾选订阅一个会话（默认自动订阅最新发起的那个，手动勾选后不被新会话抢走；再点已勾选的圆点取消订阅）：气泡旁会显示该会话的当前动作、最近调用工具与思考/消息预览，不带标签和会话名，点卡片直接进会话浮层。订阅卡优先级低于提问、插件连接和完成卡——有别的卡先显示别的，空闲时才显示订阅卡
- 已完成会话可直接右滑移除，不必点进会话；滑动不足阈值会回弹
- 气泡可以拖到任意位置、不会吸附边缘；拖动时面板跟着一起移动，关掉重开仍在原处
- 提问气泡：单选题可直接在气泡里点选项提交；多选/文本题点「在浮层回答」。交付气泡点开进对应会话浮层，浮层右上角全屏进入 App
- 插件连接流程在 App 外等待时也弹事件卡：显示插件名与当前步骤，点卡片回到 App 继续；连接结束卡片消失
- 需要系统「显示在其他应用上层」权限；部分国产系统拦截后台弹窗时还需要允许「后台弹出界面」

## 虚拟屏幕

- 需要选中无线调试（ADB）或 Root 档，且对应后端实际可用（ADB 守护运行或 Root 已授权）；插件 → 屏幕操作 → 启动虚拟屏幕，浮窗面板出现实时缩略图，点开看全屏画面；虚拟屏始终竖屏，分辨率取手机真实屏幕的短边×长边（测试机 1220×2712），与手机当前方向无关
- Agent 用 `screen_*` 工具观察、点击、滑动、输入、截图和启动应用，优先使用后台虚拟屏；可选 `target=virtual|main`，省略时默认 virtual，操作主屏须显式选择 main。失败不会自动换屏。`virtual_screen(action=start|stop|status)` 只管理虚拟屏生命周期
- 虚拟屏节点读取、ref 点击、中文输入、等待需要无障碍；无障碍关闭时仍可用坐标点击/滑动/按键/ASCII 输入/截图。应用列表无需先启动虚拟屏；启动应用与交互需要在线，不回落到主屏，也不移动主屏正在使用的应用。ref 在新观察或屏幕重建后失效；观察过滤按 AND 组合，未完成扫描时零命中不代表目标不存在。
- 虚拟屏还没画出新内容时截图会回退到最近一帧；无无障碍时 `screen_type` 只支持 ASCII；被系统挪到虚拟屏属于系统行为，`screen_launch` 会返回 `onExpectedScreen` 与可执行提示
- 停止用「屏幕操作」插件页的「停止虚拟屏幕」；连续 5 分钟没有任何 agent 的 `screen_*` 操作会自动关闭虚拟屏省电（插件页启动、悬浮窗预览都不算操作），App 进程结束后 helper 自动退出并释放虚拟屏
- 主屏无需先启动虚拟屏。主屏节点、中文输入与等待需要无障碍，截图还需要 Android 11+；坐标手势可用无障碍或已授权的 ADB/Root，ASCII 输入及完整按键需要 ADB/Root。无障碍全局按键在另一屏拥有焦点时会拒绝执行。截图失败不绕过锁屏或受保护窗口。
- 每次主屏调用均传 `target=main`；ref 不能跨屏使用，重新观察或窗口变化后需重新获取。主屏启动应用前确认任务位置，拒绝移动虚拟屏上的应用；缺少特权检查能力时，只有确认虚拟屏停止才允许主屏启动。取消或超时后先观察页面，不自动重复操作。

## 接入

- **MCP**：Streamable HTTP 服务器管理（含 OAuth、连接检测），工具/资源经 `tool_search` 按需加载，工具名 `mcp__<server>__<tool>`
- **插件**：
  - 外部（按需下载/安装/更新/卸载）：飞书、企业微信、小米云服务
  - 内部（内置，可单独启停）：目标、后台任务、定时任务、创意工坊、网络搜索、屏幕操作（含虚拟屏）、安排
  - Agent 用 `plugin_setup` 拉起连接流程；安装确认、取消、进度与系统通知由 App 统一提供，插件可在同一个 sheet 里渲染自己的界面（未提供时显示通用的阶段/链接/二维码视图）；最多等 15 分钟，超时取消本次流程（已安装部分保留）
- **屏幕操作**：一个插件管虚拟屏与主屏。原子 `screen_*` 工具支持虚拟屏与主屏，默认并优先使用虚拟屏；主屏需显式 `target=main`，通过 `screen_status` 查看两屏的真实能力。特权 helper 建后台虚拟屏，Agent 用 `screen_launch` 启动应用，再用 `screen_*` 操作；`virtual_screen(action=start|stop|status)` 管生命周期。未开无线调试/Root 时插件开关呈黄色、页面提示去「权限」开启，工具与技能都不会出现；授权后开关恢复蓝色并立即可用。
- **安排**：读写系统日历事件与提醒（需日历权限）
- **小米云服务**：WebView 登录 i.mi.com，按开关读写账号、笔记、待办、短信与通话、联系人、相册、录音；登录状态区分已验证、已失效与暂时无法验证。工具收到登录失效时即时刷新状态，较早发出的检查不会覆盖新登录或失效状态。
- **企业微信**：安装官方 `wecom-cli` 后扫码授权，操作消息/文档/日程/待办；**飞书**：安装 CLI 后走 device-flow 授权
- **技能**：zip 包安装到仓库，可全局或按工作区启用；复制到 agent 技能目录生效（不是软链）
- **语音**：系统 ASR 转写、系统 TTS 朗读。主界面与浮层的麦克风语义一致：短按切换聆听、按住说话、松手结束，聆听时仍可打字；识别结果填回输入框，设置开启「识别后直接发送」且输入为空时直接发送；设置 → 系统助手 里的「默认助手」直接跳到系统默认应用页
- **系统助手浮层**：成为默认助手后，任意 App 上长按电源/助手手势唤起。底部滑入输入卡（默认打字；模型与思考档在模型 sheet；工作区用面板标题右侧的文件夹图标打开，先选工作区再选会话；两级紧凑浮层卡，不撑高面板）；发送后从顶部滑下会话面板，高度随消息与生成内容逐行增长、最多半屏，空闲时收成内容高度（标题行 + 全屏按钮 + 完整会话，含消息、过程、失败重试、交付与提问）；键盘打开时面板顶部不动、不隐藏，底部与输入卡之间保留固定间隔并做高度动画，输入卡单独抬到键盘上方；唤起时先压暗背景，等会话与面板首帧就绪后再滑入卡片；右上角全屏进 App，点空白或返回关闭浮层。运行中发送=插话、长按发送=排队；图片/HTML 内联、文件与 md 就地预览、`ask_user_question` 就地作答。浮层光效跟随当前轮次：唤起时全屏自下而上涌起，开始回答时流光沿四边自下而上流过，思考/等待常亮低强度边缘，完成/停止收敛；进入浮层时背景压暗强调卡片层级。默认不自动开麦；设置 → 系统助手 可设置「长按唤醒」
- **分享接收**：从别的 App 分享图片/文件/文本，插入当前会话或预填输入框

## 创意工坊

- 每个创意是 Agent 按需求写的 HTML/CSS/JS 文件夹，WebView 渲染成可交互轻应用；没有分类/模板
- 内置 workshop 技能可用 `/skill:workshop` 强制加载；建好后 `workshop_load` 装载、`present` 交付；`workshop_delete` 删除创意，连同页面数据一起清空
- 页面经 bridge 读写自己的数据（SQLite，按创意隔离）；`workshop_edit` 可只改数据不重写页面；页面 JS 可用 `app.agent.*` 编排一次性 Agent
- 页面 bridge 只开放明确 API，页面数据按创意隔离；app.agent.run 是一次性 Agent，按当前配置开放文件、命令、插件和 MCP，工具和技能可主动缩减。工作文件放在默认工作区并保留；页面关闭会取消运行，结束前终止并等待本次并行命令收尾。一次性运行不提供目标续跑、提醒或聊天交付卡。

## 界面

- 常驻抽屉；设置与整页层级推入转场；统一 motion tokens 与按压态
- 浅白底、鲸蓝强调色、发丝线分隔；平面不用阴影/渐变/毛玻璃；浮起的面（输入卡、系统助手输入卡与半屏面板）用一层柔和着色投影拉开层级（开关 thumb 与分段选中 pill 除外）
- 设置 → 聊天设置：正文字号 + 过程自动折叠、自动重试、后台任务唤醒、识别后直接发送、自动朗读
- 聊天顶栏只留菜单与状态图标；系统助手页提供「默认应用设置」入口，引导把语音助手/语音输入改成 DeepDeep

## 已知边界

- 不做二次审批，只分权限档：普通 / 无线调试（ADB）/ Root；ADB 首次配对走系统无线调试配对码与 App 通知，Root 授权交给系统 root 管理器
- 有可用特权（ADB 守护在线或 Root 已授权）时，App 启动和切档会自动把 DeepDeep 无障碍合并进系统启用列表；ADB 守护进程升级后需要重新连接一次才能恢复 ADB 后端，Root 后端不依赖它
- 悬浮窗需要系统悬浮窗权限，且只在 App/助手浮层之外显示；气泡内不弹输入法
- ADB 守护进程挂在 adbd 下：关闭无线调试或重启后 daemon 会被系统清理，需要重新开无线调试并在权限页点一次连接；不联网、不暴露到局域网。虚拟屏在 Android 13 与 Android 16 实测，其他版本 best-effort；虚拟屏节点树依赖无障碍，关闭时只能坐标操作
- Linux 是 proot 用户空间，不是安全沙箱
