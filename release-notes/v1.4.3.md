# Super PI Agent 1.4.3

## 插件卡片

- 回答区的卡片只来自插件自己的工具；通过命令行使用的插件（中山大学、飞书、企业微信）改为直接返回文本，回复更直接，也不会再把迁移、兼容之类的内部提示混进对话。
- 插件页恢复全局启用开关：关掉后这个插件在任何 Bot 里都不可用；Bot 的能力页只列出已开启的插件。
- 崩溃后被自动停用的插件，可以在插件详情里重新启用。

## 中山大学

- 校园 CLI 升级到 3.6.0：课表、成绩、考试、学分、场馆空位、网费默认按可读格式输出，`sysu <站点>` 显示该站点全部命令；需要机器格式时加 `--json`。
- 登录与验证码仍然只在插件页完成。

## 稳定性

- 修改 Bot 能力、安装或删除技能后，已打开的会话立即生效。
- 修复技能安装目录、Bot 头像清理、酒店锁价、邮箱归档、校园集市凭据与代理范围等问题。

## 已知限制

- 中山大学、飞书、企业微信不再在回答区出卡片，数据以文本回答呈现；需要富卡片的能力由各插件后续以工具形式提供。
