# Super PI Agent 1.4.2

## Bot

- 抽屉里的每个 Bot 都是独立的助手：有自己的头像、名字、简介和设定，也有自己的技能、插件、连接器和工具。
- 默认 Bot 叫 PI，使用应用图标；它的能力默认全部开启，可以逐项关掉。
- 新建 Bot 时填名字、选头像、写简介即可创建；新 Bot 默认不启用任何能力，创建后到「Bot 设置」里按需打开。
- Bot 设置分三块：能力（技能 / 插件 / 连接器逐项开关）、工具（屏幕工具、小程序工具，默认关闭）、设定。
- 技能、插件、连接器页面只负责安装、登录、更新和删除，不再有全局启用开关；用不用由每个 Bot 自己决定。
- 对话顶栏现在显示当前 Bot 的头像和名字，默认 Bot 显示 PI 图标与名字。
- 抽屉导航做了精简：记忆和远程连接移到了「展开更多」。

## 市场分类

- 插件、连接器、技能三个市场页面新增分类筛选：办公、内容、开发、学习、研究、商业、设计、生活。搜索框下方的分类条会吸顶，选择分类后只显示这一类，也可以和搜索词叠加使用。

## 市场内容

- 技能市场保留 100 个精选技能，名称与标签重新整理，按用途归类。
- 连接器新增 53 个厂商官方托管的远端服务，例如 GitHub、GitLab、Sentry、Supabase、Vercel、MongoDB、飞书、钉钉、天眼查、腾讯地图、麦当劳中国。首次连接按提示在浏览器授权，或填入对应服务的 Token。
- 插件保持原有条目，更新了分类与标签。

## 本地 ADB

- 修复华为/HarmonyOS 等没有无线调试入口时的首次连接：点「连接并启动」后手机会弹出「允许 USB 调试」，允许即可连上，不再直接报未授权；本地面板会显示等待授权与失败原因。手机重启后仍需在电脑重新执行一次 `adb tcpip 5555`。

## 已知限制

- 大部分连接器需要厂商账号，部分高级功能取决于账号套餐。
- 麦当劳中国需要先在开放平台申请 MCP Token；高德、百度地图等只能在链接里带 Key 的服务暂未收录。
- 分类筛选需要市场索引更新后才会出现：打开市场页右上角刷新一次即可。
