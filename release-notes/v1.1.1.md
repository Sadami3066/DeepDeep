# DeepDeep 1.1.1

这一版把天气、火车票、酒店和打车四个插件从「能查到」补齐到「能顺着下一步完成任务」，并把官方插件重新收口到 API level 6。

## 出行与天气

- 火车票支持选择日期、交换出发到达、记住最近路线，以及完整车次列表。查到车次后可以直接打开 12306，路线和日期已经带好，登录、选座和支付都在 12306 完成。
- 酒店支持在对话里搜索酒店、查看房型和订单，结果以卡片展示；需要预订时打开 RollingGo 完成。插件页负责安装、登录和恢复，不再让用户在页面里猜下一步。
- 打车把密钥从明文设置迁到加密存储，保存时会验证连接；车型预估、叫车链接、订单和司机位置都有完整的卡片与错误状态。插件仍然不会直接发单。
- 天气会记住最近查询的城市，支持 3 / 5 / 7 天预报；聊天卡片可直接打开完整预报。

## 插件与界面

- 插件激活失败时，失败提示旁直接出现「重试激活」，不用先打开行尾菜单。
- 十一个官方插件全部重构建、重签名并安装到当前设备，已安装的旧版本不会再停留在 API level 5。
- 这一轮没有改变插件 API level，已有插件能力保持兼容。
