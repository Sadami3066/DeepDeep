# DeepDeep 1.0.8

这一版把主题、插件界面和聊天里的几处细节一起补齐，并让插件把「Agent 能自己完成的事」交还给 Agent。

## 主题

- 设置 → 主题新增「来自插件」分组：安装主题插件后，可一键切换整机配色，主界面、插件页、系统助手浮层、悬浮窗与状态栏一起变化。
- 新增官方「主题」插件，内置海盐、苔原、晚霞、樱、墨玉、夜航、咖啡、石墨 8 套浅色/深色配色。
- 主题包在安装时校验格式与文字对比度；主题被停用或卸载时自动回到默认主题。

## 聊天

- 完成后的「已完成 · x 个思考 · x 个工具」变得更小更淡，不再抢正文的视觉重心；运行中的状态保持原样。
- 工具或技能在下一回合发生变化时，会出现一条低调提示，并同时告知模型，接下来的回答能直接用上新能力。
- 点击聊天里的邮箱搜索/阅读卡片会直接在聊天上打开这封邮件的 sheet，不再先进插件页；可以读正文和图片、看附件、回复、归档或删除，返回即回到聊天。

## 邮箱

- Agent 新增 `mail_send`：你明确要求发送时，可直接完成「起草 → 发送」，不必再去草稿卡片上点一次；草稿卡片仍保留手动发送。
- 邮箱插件 1.4.0 同时做了卡片 sheet、动画与错误提示的打磨。

## 官方插件

飞书、企业微信、中山大学、微信导出、小米云服务同步升级（飞书与微信导出另修正了卡片内边距）：首屏改成人类可读的状态摘要，安装/授权有阶段进度与取消，错误就地提示并可重试，子流程有返回与过渡，页面底部留白和深浅色统一。具体版本：

- 飞书 2.2.1
- 企业微信 2.2.0
- 中山大学 CLI 2.2.0
- 微信导出 0.5.1
- 小米云服务 2.2.0
- 邮箱 1.4.0
- 主题 1.0.0

以上插件均要求 DeepDeep 1.0.8+。
