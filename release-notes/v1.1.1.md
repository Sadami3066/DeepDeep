# DeepDeep 1.1.1

这一版把火车票、酒店和打车插件从「能查到」补齐到「能顺着下一步完成任务」，新增高德地图，并把官方插件重新收口到 API level 6。

## 出行

- 火车票支持选择日期、交换出发到达、记住最近路线，以及完整车次列表。查到车次后可以直接打开 12306，路线和日期已经带好，登录、选座和支付都在 12306 完成。
- 酒店支持在对话里搜索酒店、查看房型和订单，结果以卡片展示；需要预订时打开 RollingGo 完成。插件页负责安装、登录和恢复，不再让用户在页面里猜下一步。
- 打车把密钥从明文设置迁到加密存储，保存时会验证连接；车型预估、叫车链接、订单和司机位置都有完整的卡片与错误状态。用户确认车型和价格后可以直接创建滴滴订单，支付仍在滴滴内完成。
- 酒店支持创建待支付订单：用户确认酒店、房型、日期和总价后，插件锁价并下单，卡片给出 RollingGo 官方支付链接；插件不代替用户支付。

## 插件与界面

- 插件激活失败时，失败提示旁直接出现「重试激活」，不用先打开行尾菜单。
- 所有工具在过程区统一显示原始调用卡；酒店、火车票、打车、邮箱等插件提供的富卡片只出现在回答区，不再混入过程折叠区。
- 十一个官方插件全部重构建、重签名并安装到当前设备，已安装的旧版本不会再停留在 API level 5。
- 官方插件按品牌命名与图标：12306铁路、滴滴打车、RollingGo酒店；新增高德地图插件。
- 飞书、企业微信、中山大学 CLI、小米云的插件页统一为状态摘要、单一主操作和就地重试，阅读与操作更集中。
- 天气查询交给网页搜索，不再保留独立天气插件。
- 这一轮没有改变插件 API level，已有插件能力保持兼容。
