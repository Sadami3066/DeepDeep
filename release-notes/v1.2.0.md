# DeepDeep 1.2.0

这一版把回答区从“工具结果自动铺卡片”改成“模型决定展示什么”，并重做了每个插件卡片的版式。

## 回答区

- 工具执行结果不再自动变成卡片：工具只提供事实与一张待展示卡片，模型决定是否在回答里展示它。
- `present` 成为唯一的展示入口，除文件、图片、视频、网页与小程序外，还能交付工具结果里的卡片；数量与取舍由模型判断。
- 同一回合里过程折叠成一条，卡片只出现在该出现的位置；模型没选中的结果不会占满屏幕。

## 卡片

- 飞书：会话列表、消息气泡、日程时间轴、云文档搜索与文档摘要、任务清单各自成型。
- 企业微信：群聊、会话消息、文档、日程、待办、通讯录按企业通讯场景重排。
- 中山大学：课表改成周历时间网格，成绩以绩点与学分为锚点，考试带日期与倒计时，待办、场馆预约与网费各有版式。
- 高德：地图作为主视觉，地点行带距离与标签，路线是交通时间轴，天气用温度大数字与未来几天气条。
- 酒店：搜索卡以图片与起价为主，房型按每晚价排列，订单是状态时间轴，预订是确认信息。
- 打车：估价卡是车型选择，订单卡有司机与车牌，起终点用节点连线。
- 12306：车次改成车票式排版，出发到达时间、历时、车次与坐席价格分层显示。
- 小米云：空间配额、便签、勾选清单与文件行分开设计。
- 邮箱：搜索是信封列表，读信是信纸，草稿是写信预览。
