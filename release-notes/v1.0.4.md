## DeepDeep 1.0.4

本次更新升级插件系统底层契约，并修复自定义服务商在局域网下的连接问题。

### 插件

- 插件系统升级到新的稳定契约（plugin-api 1.0.0 / API level 6）：插件需要更新到新版本才能继续使用。
- 官方五个插件（飞书、企业微信、中山大学、小米云服务、微信导出）已同步升级；更新 App 后到「插件 → 市场」更新到最新版本即可。
- 旧版本插件（API level 5）在 1.0.4 上会被拒绝加载并提示更新，不再兼容。
- 市场条目会标注运行所需的宿主版本，版本不足时禁用安装。

### 模型与聊天

- 自定义服务商支持本机与局域网的 `http://` 地址：获取模型列表与对话都能正常连接，明文地址会在编辑页给出提示。
- 新增或修改自定义服务商后，已打开的会话立即生效，不需要重启 App 或重开会话。

### 提示

- 更新不会删除本机会话、设置与凭据；更新插件版本时插件自己的数据会保留。
