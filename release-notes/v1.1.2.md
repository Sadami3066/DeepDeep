# DeepDeep 1.1.2

这一版补齐 CLI 插件在对话里的卡片体验，修复流式正文抖动和 Root 环境路径问题。

## 对话与插件

- 飞书、企业微信、中山大学 CLI 的常用读取命令现在会在回答区生成插件卡片，同时把完整事实整理给模型；原始长 JSON 不再直接丢给模型。
- 飞书、企业微信的插件页可以检查并安装新的 CLI 组件，安装包校验通过才更新，失败保留旧版本。
- 高德的地点、周边、坐标和路线卡片加入静态地图预览；点地图可以在高德中打开。
- 小米云补充账号、笔记与待办卡片；酒店房型合并价格方案，滴滴补地点坐标/预估时长，12306 修复城市站名歧义并支持查票价。
- 邮箱删除了“卡片已展示，不要重复”的提示语，让模型按事实正常回答。

## 聊天与系统

- 修复长正文流式输出时，过程摘要高度动画和插件卡片插入造成的正文上下抖动；工具过程卡与回答区卡片继续分层。
- 修复插件工具后置钩子生效、前置钩子被吞掉的问题，CLI 卡片桥可以正常关联命令。
- Root 模式下 `/data/user/0` 与 `/data/data` 在 bash 和文件工具中保持一致，系统提示补充路径说明。
