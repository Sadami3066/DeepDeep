# DeepDeep 1.4.0

## 返回三层：raw / guidance / card

工具结果统一分成三层，插件不再自己写“清洗摘要”：

- `deepdeep.raw`：上游完整输出。CLI 结果去掉 ANSI、`[exit: N]` 与宿主提示；第三方 CLI/MCP 数据保持原样；我们自制的 CLI 在生产者层就输出最终格式：中山大学只输出 JSON，12306 输出完整可读文本；小米云没有 CLI，raw 是上游完整响应。
- `deepdeep.guidance`：给模型的短指导，只写下一步、失败原因、约束和分页/登录提示，不复述数据。
- `deepdeep.card`：卡片标题与全量 payload，模型用 `present` 交付，卡片渲染不再裁剪数据。

宿主在所有插件 hook 之后合成模型可见文本：raw 存在时以 raw 为正文，追加 guidance 与“卡片 id”；错误结果不追加卡片 id。旧会话保持原样。

## 宿主与 SDK

- `plugin-api 1.3.1`：新增 `ImageService`（`host.images().load(url, maxEdgePx)`）与 `IMAGES` capability，插件卡片可以加载远程图片。
- 宿主图片缓存：内存 LRU + 应用私有 cacheDir，单图上限 6 MB、请求去重、失败回退、http→https、采样解码；不写共享存储或相册。
- `design 0.11.0`：新增 `DdRemoteImage`（加载器由插件注入，组件不直接联网）。
- 版本：app 1.4.0 / versionCode 10105；`plugin-api 1.3.1`、`design 0.11.0`；官方插件：飞书 2.7.0、企业微信 2.6.0、中山大学 2.7.0、微信导出 0.5.2、小米云 2.7.3、邮箱 1.6.1、滴滴 1.3.0、酒店 1.4.1、高德 1.5.2、12306 1.4.0、主题包 1.0.1、校园集市 1.0.18；`minHostVersion` 1.4.0。插件市场同批发布 `plugins-20261116`，包含 12 个官方插件制品。

## 已知限制

- 高德的地点搜索和周边本身不返回坐标、距离、评分、电话，也不支持翻页；路线不含轨迹串，路线卡的静态地图只画端点（上游有 polyline 时才连线）；驾车可能只有 1 条方案。
- 12306 按城市语义返回，一个车次可能有多个实际上车站/到站组合；偶发某行日期与查询日期不同。以上均透传并标注，不做静默合并。
- 交通路线不返回轨迹坐标串，地图只画起终点。
- 飞书群主只有 `owner_id`，租户域名与系统消息占位符实值上游不返回；邮箱是否开通需 `profile` 的 `not_found_reason` 判断。
- 酒店的预算 `max_price` 由上游筛选，返回数量可能少于 size，卡片会明确“已按预算筛选”；上游若忽略预算仍会标注超预算。排序由上游决定；部分房型缺面积/窗户/入住人数，床型可能是“或”，取消原因只在订单详情。
- 待办/联系人接口是增量同步，没有下一页；便签列表仍用 syncTag 翻页、录音用 offset；短信 syncTag/syncThreadTag 返回空即表示到末尾。
- 中山大学的请假提交与站点登录验证码不再在终端交互：请假需要显式 `--dry-run` 或 `--yes`，验证码由插件页用 `--code` 续接。
- 图片只做临时缓存；上游链接失效或防盗链时卡片显示占位图。
