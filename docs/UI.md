# UI design

## 参考

- Claude Android App：顶栏、左侧用户气泡、全宽 assistant、浮动 composer、Claude 式分组设置。
- DSH Web chat：流程化展示思考、工具调用与结果；过程折叠/展开；working 状态。

只借鉴布局与信息组织，不复制代码或素材；颜色、字体、图标仍使用本项目的「晴潮」设计系统。

## 聊天

- 顶栏：菜单 / wordmark / 新对话 / 更多。
- 用户消息：左侧浅色气泡；assistant：全宽 Markdown。
- Composer：模型 chip、思考 chip、输入、发送/停止；无未实现按钮。
- Working：运行中始终显示 activity + 耗时。
- 过程区：过程摘要 + reasoning/tool 卡片。运行中展开；完成后可折叠，默认展开。
- 工具卡：名称、参数预览、运行/完成/失败、耗时；展开显示完整参数与输出，可复制。
- 自动跟随：底部跟随；用户上拖后停止并显示“回到底部”。

## 抽屉

- 顶部功能项带图标：聊天、已归档、新建对话。
- 历史项纯文字，不堆图标；置顶区/最近区。
- 长按：重命名、置顶、归档、删除（删除确认）。

## 设置

Claude 式分组卡 + 图标行 + 发丝线。真实项：Provider、运行环境、颜色模式、关于/许可。其余占位项点击给出“尚未接入”反馈。思考等级只在聊天 composer。

## Provider

- 42 家 Provider 全量列出，首字母占位徽标，后续替换真实图标。
- 详情：Base URL、模型数、API Key 只写保存/清除、OAuth 占位、模型选择 + 设为当前。
