生成命令

在仓库根目录（app/）执行；--check 只校验漂移不写文件，可直接用于 CI。

node design/icons/gen.mjs
node design/icons/gen.mjs --check

分类与命名

项位置 / 值说明
图标源design/icons/<category>/<id>.png|.xml唯一手改入口
登记表design/icons/catalog.jsonid / 分类 / 中文名 / DdIcons 成员 / 上游路径
生成入口design/icons/gen.mjs写出运行时资源、DdIcons.kt、本预览页
运行时资源design/src/main/res/drawable-nodpi/ic_<category>_<id>.png|.xml只读，由脚本覆盖
预览页design/icons/preview.html本页，图标读同目录源文件

源文件与 id 用 snake_case；生成资源名 = ic_<category>_<id>；DdIcons 成员名保持历史命名，调用点无需改动。

新增或替换图标

  1. 把 PNG 放进对应分类目录（或手写 vector XML），文件名即 id；
  2. 在 catalog.json 的 icons 中登记 id / 分类 / 中文名 / DdIcons 成员 / 上游路径；
  3. 运行生成命令并编译；未登记或未使用的源文件会让生成失败，避免留下死资源。
