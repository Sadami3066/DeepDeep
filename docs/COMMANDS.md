# 命令

聊天输入框支持 `/` 命令。命令只在本地执行，不发送给模型，也不写入会话 JSONL；需要反馈的结果（如压缩）以消息流里的灰字提示呈现。

## 使用

- 在输入中的任意词边界输入 `/`（行首，或空格/换行后的第一个字符）会展开命令面板；面板是一个可滚动的背板，条目在板内排列，命令变多时不会挡住消息。
- 按名称、标题或说明过滤；点选条目执行。输入中命令前后的其他文字会保留，命令本身从输入框移除。
- 已知命令只有在整行就是一个命令时才会被发送键执行；未知命令不发送，输入框下方显示提示。
- 以 `/` 开头的普通文本不会被当成命令；前导空格可发送普通文本。

| 命令 | 参数 | 行为 |
|---|---|---|
| `/compact` | 无 | 立即压缩较早的历史，显示压缩前后 token 数；运行中、无可压缩历史时有对应提示 |
| `/goal` | `[目标文本 \| pause \| resume \| clear]` | 无参打开目标 sheet；文本创建目标；pause/resume/clear 直接操作 |

## 说明

- 命令面板只服务于人；模型侧的能力仍然通过工具调用（`get_goal`/`update_goal`、`job_start`/`job_output`/`job_list`/`job_kill` 等）完成。
- 压缩由 SDK 执行，自动压缩仍按上下文阈值触发；`/compact` 只是手动入口。
- 目标续跑会在消息流里留下目标轮提示并开启新的一轮；后台任务唤醒会开启新的一轮，只在回复上方留一行极简任务标记，不显示完成/失败卡片。
