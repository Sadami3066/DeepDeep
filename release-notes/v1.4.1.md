# DeepDeep 1.4.1

## 小程序

- 小程序现在可以直接调用系统能力：通知与定时提醒（页面关掉也会响）、选择/读写/导出文件、系统分享、剪贴板、相册与拍照、扫码、朗读与语音输入、打开链接、定位、日历、触感与屏幕常亮。首次使用会请求系统权限。
- 页面可以用 `app.env()` 查看当前可用的能力和安全区，用 `app.on()` 接主题、前后台切换和点通知打开的事件。
- 查看器顶栏新增全屏按钮：隐藏 App 顶栏并按小程序记住，系统返回键退出全屏。
- 技能文档与样例同步更新；已有小程序不用改动。

## 系统访问

- ADB 档新增「本地 ADB」连接方式。系统没有无线调试入口时（例如部分华为/HarmonyOS），先用电脑执行一次 `adb tcpip 5555`，再到「设置 → 系统访问 → ADB → 本地 ADB」点「连接并启动」；首次连接在手机弹窗里允许调试授权即可。手机重启后需要重新执行一次电脑命令。

## 插件

- 邮箱插件 1.6.2：修复 163/126 邮箱登录成功但同步失败的问题（按网易要求补充 IMAP 客户端标识）。插件市场同批更新，插件页刷新即可升级。

## 已知限制

- 小程序的相机、相册、语音、定位、日历等能力需要系统授权；拒绝后页面会提示，可在系统设置里重新开启。
- 本地 ADB 依赖电脑执行 `adb tcpip`，手机重启后需要重做一次。
- 163/126 邮箱需要在网页版开启 IMAP 并使用授权码；修复后仍然失败，请把账号页的错误详情反馈给我们。
