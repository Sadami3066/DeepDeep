# UI design

## 参考

- Claude Android App：顶栏、右侧用户气泡、全宽 assistant、浮动 composer、Claude 式分组设置与层级推入。
- DSH Web chat：过程化展示思考、工具调用与结果；运行中展开、完成后收纳。

只借鉴布局与信息组织，不复制代码或素材；颜色、字体、图标仍使用本项目的「晴潮」设计系统。

## 配色

- 页面底色：浅白
- 卡片、抽屉与浮层：纯白
- 强调色：鲸蓝
- 层次只靠字重、不透明度、留白与发丝线；常规面不用阴影/渐变/毛玻璃，仅开关 thumb 与分段选中 pill 带柔和投影。
- 分隔线统一 0.45 alpha 发丝线。

## 聊天

- 顶栏：菜单 / wordmark / 更多；不提供顶栏新建会话。更多菜单只有「重新加载」：重新读取当前会话的 skills/AGENTS.md，运行中不可重载；重载期间顶栏显示一个小加载圈，完成后消失。新建会话只从抽屉工作区行展开后的 + 发起，Home 也是工作区之一。
- 用户消息右对齐；assistant 全宽 Markdown。
- Composer：模型 chip、思考 chip、输入、发送/停止；无未实现按钮。
- 模型 sheet：顶部「厂商」行可下拉切换已配置厂商（切到该厂商下当前模型或首个模型），下方列出该厂商的模型（数量多时可滚动，上限约 520dp）；只列已配置（API Key 或 OAuth）的厂商。下拉使用专属的 `DdDropdown`（锚在行下方、与锚同宽、淡入 + 轻微上移），与长按上下文菜单 `DdMenu` 明确区分。
- 运行中固定状态行：打字点 + activity + 耗时，不随流式文字移动。
- 过程：运行中自动展开；工具/思考行默认收起；「过程自动折叠」开启时，最后一段结果文本一开始输出就把过程折叠、结果移到过程外继续流式显示；关闭后过程一直保持展开，直到用户手动收起。
- 中间文本和工具按事件顺序进入过程；过程文本同样走 Markdown。
- 工具行极简：monospace 名称、参数预览、状态、耗时；展开才显示详情。
- Markdown：嵌套列表/任务、块级图片（异步加载 + 淡入 + 失败占位，点击全屏预览）、超宽表格横向滚动、代码语法高亮（语言标签 + 复制）、递归引用块、setext 标题、转义/硬换行、自动链接与引用式链接、内联 HTML（粗斜体、code、kbd、上下标、彩色 span）、数学降级渲染、脚注上标 + 文末列表、任务列表、引用条、有序列表起始值。
- 选择文本：长按 assistant 回答或用户气泡进入系统文本选择（可跨段落/代码/列表），拖动左右手柄可调整范围；自绘选择工具条使用文字标签：复制 / 全选 / 引用 / 朗读（全选后菜单保留，可继续操作）；点选区外或点其他消息自动取消选择并收起菜单。不再使用长按消息菜单。助手回答下方不再显示 copy/quote/share 图标行；代码块仍保留复制按钮。
- 引用：工具条把选中文字送入 composer 顶部的引用预览（2dp 竖条 + 2 行省略 + X），发送后用户气泡内以竖条引用块展示，并作为 blockquote 前缀发给模型。
- 朗读：选中文字用系统 TTS 从头播放，再次朗读或离开页面会被新朗读覆盖。
- 设置：「聊天设置」页有三个开关：过程自动折叠、自动重试（默认开启）、后台任务完成时唤醒（默认开启）；触感反馈、发送后收起键盘、流式输出跟随、显示思考过程在逻辑上固定开启，UI 不再显示。颜色模式在设置主页。
- 键盘：IME 高度变化逐帧驱动聊天内容上移/回落，不做「键盘完全展开后二次跳动」；键盘弹起时打开抽屉也保持平滑。
- 附件：composer 回形针打开系统文件选择器（可多选）；选中后在输入框上方显示 Claude 式预览卡（图片缩略图 / 文本内容片段 / 文件图标 + 名称），横排可滚动、右上角圆形 X 可移除，最多 20 个；发送后附件在气泡外排成一行横向滚动：图片与文件统一 140dp 方形卡（图片按裁切填满、文件卡带扩展名徽标），不换行，下方才是文字气泡（回复引用仍在气泡内）。文件复制到 workspace/attachments 供 agent 用 read/bash 读取，消息里以 `<attachments>` 块携带路径。
- 附件预览：点击气泡附件或 composer 预览卡打开全屏预览；图片直接渲染、`.md` 用聊天同款 Markdown 渲染、其他文本等宽滚动、其他类型显示“无法预览此文件”；右上角分享按钮通过 FileProvider 调起系统分享。
- 文件引用：assistant 消息中的 `attachments/…`、`workspace/…`、`/…/files/home/…`、`/…/files/workspaces/…`、旧 `/…/files/workspace/…`、`file://` 路径、行内 code 路径和指向这些路径的 markdown 链接都渲染为可点击链接（accent + 下划线，不再套 monospace/背景胶囊），点击按 workspace 解析后打开预览；文件不存在时 Toast 提示。
- 行内代码：反引号 code span 按 CommonMark 规则匹配（多反引号、首尾空格裁剪、换行归一化）；workspace 路径仍是链接样式；其他相对/绝对/文件路径用 monospace + 次级文字、无背景；普通行内代码使用主题浅蓝底（accentSoft）+ 4dp 微圆角，按文字基线包裹（含 j/y/g 等下行字母），左右留少量内边距，换行时按行拆分。
- 自动跟随：用户上拖后暂停并显示“回到底部”。
- 新会话空态：mascot 立绘（480 WebP，透明底）居中显示在 greeting 上方，浅色/深色主题均可用；无会话内容时不占列表空间。
- 提问：`ask_user_question` 的互动卡内联在聊天里（过程区下方、正文上方），不弹 sheet。同一时间只显示一张卡；同一轮里先后或并发多次提问时，回答完当前问题后同一位置出现下一张。一次一题 + 进度 + 选项/描述 + 多选 + 自定义答案 + 跳过/上一题/下一题/提交；点标题行可平滑收起/展开；`(Recommended)` 显示为「推荐」标签，回传保留原 label。提交后卡片显示「已提交」，工具结束后互动卡消失，回答按工具调用顺序收进过程：ask 工具行后面出现「已回答 · N 个问题」，点击可展开只读问答（含每题回答或「已跳过」）。问题属于其他会话时，composer 上方显示「另一个会话正在等待回答 · 前往回答」。
- `/` 命令：在行首或空格后输入 `/` 时 composer 上方展开命令背板；列表先 App 命令（压缩上下文、目标、创意工坊技能），下面列出已启用的技能 `/skill:<name>`，可滚动、按名称/标题/说明过滤；点选只把完整命令**补全到输入框**（命令以强调色显示），不会直接执行，补参数后按发送才执行；未知命令在错误行提示且不发送；命令文本不进入会话；`/skill:` 发送时把技能正文作为用户消息展开；压缩完成后消息流留一条「上下文已压缩：A → B」灰字。
- 目标续跑提示：消息流中显示一条带 Sparkles 图标的「目标 · 第 N 轮（/M）」+ objective 两行摘要，和其他灰字提示区分开；目标完成或阻塞时各留一条「目标已完成」/「目标已阻塞」灰字。
- 上下文：composer 上方右侧一个小圆环 + 百分比；点击打开「会话统计」sheet：上下文占用 `~已用 / 窗口`、自动压缩阈值、本会话输入/输出/缓存读/缓存写与费用；上下文是「最近一次 provider 用量 + 新增内容估算」，累计 token 与费用来自 provider 上报。
- 目标：当前会话有目标时 composer 上方显示目标条（objective + 阶段 + 第 N 轮（可选 /M）+ 暂停/继续），目标条不再打开弹窗；用 `/goal <目标>` 直接创建，`/goal pause|resume|clear` 控制；默认不限轮次，模型显式指定时才有上限；进程重启后目标显示为暂停，需要手动继续。
- 交付卡片：模型调用 `present` 后，聊天里在 assistant 正文下方显示一行与附件同尺寸（140dp）的方形文件卡，横向滚动排列；卡内是文件类型图标 + 文件名，整张卡点击打开，右上角一个无底色的分享图标调起系统分享。图片/文本用内置预览打开，其他类型交给系统应用；文件缺失或无法打开时 Toast 提示。
- 文件浏览：右上角「...」菜单 →「目录文件」打开当前会话工作区的文件浏览器 sheet；顶部路径行可逐级返回，目录在前、文件在后（带大小），点文件按现有预览/系统应用流程打开。
- 后台任务：运行中数量显示在 composer 上方 token 用量行、用量环左侧（Terminal 图标 + 数字，>0 时显示）；点击打开后台任务 sheet，运行中在前（可展开实时输出、每秒刷新、二次确认停止），已结算在后（可展开输出、可清除）。任务完成按「聊天设置 → 后台任务完成时唤醒」决定是否让模型开新一轮；任务完成提示不进入聊天消息流；唤醒轮只在 assistant 回复上方留一行极简标记（Terminal 图标 + 「后台任务 · 名称」，失败时文案对应），不显示完成/失败卡片。任务入口只在用量行，顶栏没有任务图标。

- 定时提醒：用户气泡上方显示「定时提醒 · 名称」小标签（时钟图标 + 11sp 次级文字），气泡正文只显示提醒内容；历史重新打开时同样生效。
- 当前会话有启用提醒时，顶栏 wordmark 右侧、更多菜单左侧显示时钟按钮，点击进入定时任务页。
- 运行失败：该轮显示本地化错误（最多两行）+「重试」文字操作；重试把上一条用户消息重发为新一轮。错误文案按语言环境生成，401/402/429/5xx/超时/网络/模型不存在分别有对应文案，无法识别的错误附厂商原文。
- 再次打开会话时始终以后端历史为准（修复了「后台事件建空缓存后会一直空白」的问题）；运行中的会话打开后接管流式输出。

## 切换会话

- 抽屉是覆盖层，聊天内容保持常驻；抽屉用 draw-phase translation 滑入/滑出。wordmark 右侧搜索图标进入独立会话搜索页。
- 工作区直接纵向排列（Home 作为默认工作区在列），每个工作区行右侧是展开/收起 chevron；点击行展开该工作区的会话，可同时展开多个工作区。没有「历史对话 / 置顶」分组小标题，也没有当前工作区/当前会话的强调色。
- 工作区支持置顶：长按工作区 → 置顶/取消置顶，置顶工作区排在列表最前并显示小 pin 图标；Home 不可重命名/删除。
- 会话置顶只在所属工作区内生效：置顶会话排在该工作区最前，行尾用 13dp pin 图标替代相对时间；运行中的会话行尾显示 12dp spinner；有启用提醒的会话，行首图标由 Message 换成 Clock。
- 工作区行展开时行尾出现 +，在该工作区新建会话；长按工作区菜单：置顶/取消置顶、设置，非 Home 追加重命名/删除。长按会话：重命名、置顶、归档、删除。
- 层级：工作区为主级（原有 Folder 图标 + 15sp medium ink 名称），会话为次级（原有 Message 小图标 + 13.5sp inkSecondary，缩进对齐工作区名称），工作区之间 6dp 分组留白，空工作区提示缩进且降级。
- 工作区与会话的展开/收起用 LazyColumn item 动画；首次打开会话显示短转圈，历史加载完成后替换，不横向推入页面。
- 再次打开访问过的会话：立即展示内存中的消息快照（无转圈），SDK session 在后台打开；在此期间发送会等待 session 就绪后再提交。

## 图标与素材

- 图标继续使用 `design` 模块原有的 XML VectorDrawable 图标库；抽屉工作区/会话行复用原有 Folder / Message 小图标建立层级，不再引入 `assets/icons` 的新图标集。
- 空态插画：`assets/mascot/generated/mascot_welcome.png` 导出为 `app` 的 480×480 透明 WebP（约 56KB）；`assets/` 其余候选图不进入 APK。
- 所有普通图标仍由 `DdIcon` 统一 tint，不新增图标动效；插件图标例外：飞书使用彩色品牌 logo（`tintIcon=false`），网络搜索用 `DdIcons.Globe` 随主题 tint。
- 厂商图标：42 家全部使用彩色品牌标（浅色/深色两套随系统切换），不再区分单色/彩色；来源为 LobeHub MIT + Radius 官方图示，许可见「开源许可」。
- 字体：5 套随 APK 打包的拉丁字体（Instrument Sans / Geist / IBM Plex Sans / Newsreader / Lora），默认 Newsreader；中文始终回退系统字体。字体页只切换排版，不改变颜色、字号层级或代码等宽，预览词为「我思故我在 / I think, therefore I am.」。

## 个性化

- 设置 → 个性化：称呼、交互体验（安静/默认/主动）、提示词（热情/可爱/冷静/自定义）、用户指令输入框。
- 提示词预设把文本填入输入框；用户一改即标记为自定义。指令不设长度上限。
- 提示词由 runtime 组装为 `<system>`（身份、环境、隐藏的交互规则）+ `<instruction>`（用户长期偏好）；界面只展示用户自己的指令，不展示隐藏段落。
- Skills 的 `<skills>` 块由 SDK 单独注入，不在个性化页编辑。

## 插件

- 抽屉功能项为 创意工坊 / 技能 / MCP / 插件 / 定时任务，插件图标为 puzzle。
- 插件页：标题右侧是刷新图标；每行左侧是插件图标，中间是插件名 + 摘要，右侧是启用开关（未安装时显示「下载」文字按钮）；删除只在详情页。
- 详情页：标题右侧刷新；状态、版本、大小、插件自带的详情行（飞书：CLI 版本、已授权权限数量、应用是否创建、缺失权限）、技能；插件自己的操作行（连接飞书 / 应用权限 / 重新授权 / 退出登录），框架操作（更新 / 重新安装 / 删除插件，删除有确认弹窗）。已关闭插件隐藏插件操作行。
- 安装/连接/更新/删除进行中时操作禁用；错误显示在页面底部。
- 全局 setup sheet：标题「连接 <插件名>」；未安装时先显示「需要先下载插件」+「下载并继续」；下载/安装显示进度；需要浏览器时显示「打开浏览器」、链接文本与等待提示；底部「取消」会终止底层进程。授权成功后 sheet 自动关闭，App 尝试回到前台。
- Agent 调用 `plugin_setup` 时弹出同一个 sheet；用户取消后模型收到取消结果；已关闭插件返回「插件已停用」。

## 技能与工作区设置

- 抽屉「技能」→ 仓库页：右上角安装 `.zip`；空态说明；列表显示名称/描述/全局开关；点击详情查看正文、删除。插件技能也出现在仓库页，关闭插件时变为未启用。底部不再显示说明文字。
- 工作区长按菜单的「新建会话」改为「设置」；行内 + 仍新建会话。设置页两行：项目技能、AGENTS.md。
- 项目技能 bottom sheet 展示全部仓库技能；全局启用的技能固定开启、不可关闭并标记「全局」，其余多选后复制到 `.pi/skills`；仓库为空时提供「去安装技能」。
- AGENTS.md bottom sheet 使用大文本区，保存到工作区根目录；存在 `AGENTS.override.md` 时编辑实际生效文件并在界面标明。空内容删除文件。

## 定时任务

- 入口：抽屉「定时任务」；聊天顶栏时钟按钮直达。列表按「已启用 / 已停用」分组，无卡片容器，行高 ≥56dp，发丝线分隔。
- 行：名称 + 次行「下次投递时间 · 规则 · 会话标题」+ 右侧启用开关；已停用行整体降透明度，不加删除线。
- 空态：只有一句「还没有定时任务」居中显示，无按钮、无插画；新建走右上角「＋」。
- 右上角「＋」打开编辑器（新建 / 点击行编辑共用）：名称、提醒内容、重复开关、按类型显示字段、投递到（会话选择器：最近未归档会话，显示工作区）、启用开关；底部实时显示「下次：<时间>」。
- 重复开关：开 = 按 cron 表达式重复，关 = 仅运行一次。关时显示日期（月历网格）+ 时间；开时只显示 5 段表达式输入和输入框下方实时渲染的小字时间设定（如「每天 09:00」「每周一、周三 09:00」「每 15 分钟」「每月 1 日 09:00」），无效时显示错误色提示；不显示语法说明。
- 早期版本的每天/每周任务在编辑器中打开后会以等价的 cron 表达式回显，保存即完成迁移。
- 底部：主按钮「保存」；编辑已有任务额外提供「立即运行」与「删除」（删除走确认弹窗）。校验错误内联显示在表单底部，不弹窗。
- 保存后列表立即更新（订阅 `ScheduleService.schedules`），无轮询；标题缓存来自 `runtime.sessionTitle`，会话不存在时显示「会话已删除」并禁用打开。
- 立即执行立刻把提醒投递到绑定会话并跳到该会话；不改下次投递时间。
- 一次性任务投递后进入「已停用」分组，显示上次投递时间。

## MCP

- 入口：抽屉「MCP」；顶部返回 + 标题 + 刷新图标 + 「+」。
- 列表：无卡片、发丝线分隔；行 = 名称 + 次行（服务器 host · 状态）+ 右侧启用开关；状态包括已连接 · N 个工具 / 需要登录 / 连接失败 / 未测试 / 已停用 / Android 不支持。进入页面自动检测已启用的 HTTP 服务器，标题右侧刷新图标重新检测。
- 添加：点「+」打开「导入 JSON」sheet，粘贴 `{"mcpServers":{...}}` 一次导入一个或多个服务器；`streamablehttp`、`streamable-http`、`http` 等写法都会规范成 SDK 接受的 streamable HTTP。导入失败时 sheet 内显示错误，不写坏原配置。
- 编辑 sheet：直接显示该服务器的 `"name": { ... }` JSON，可改字段或重命名后保存；支持「测试连接」「删除服务器」；HTTP 且没有 Authorization 头时提供 OAuth「登录 / 退出登录」。启用状态仍在列表页开关。
- OAuth：打开浏览器完成授权；收不到回调时可粘贴浏览器地址栏的回调链接。登录成功后自动重连并重新检测。
- 工具：服务器工具在对话中经 `tool_search` 按需加载（deferred 默认），资源类工具自动注册；聊天过程里工具名以 `server · tool` 显示。
- 配置保存在 App 私有目录 `files/agent/mcp.json`；删除/停用立即对已打开会话生效。

## 创意工坊

- 入口：抽屉「创意工坊」，排在技能之前；顶部返回 + 标题 + 刷新图标 + 「+」。
- 列表：无卡片、发丝线分隔；行 = 创意 icon（manifest 的 emoji，缺省 ✦）+ 名称 + 说明（manifest.description，可为空）+ chevron；失效目录显示「格式无效 · 原因」，点击可确认删除；空态为编辑图标 + 「还没有创意」+ 一行创建提示。
- 新建：`+` 直接新建一个 Home 会话并跳回聊天，输入框预填 `/skill:workshop `，用户接着输入想法发送即可；不再有新建对话框或类型选择。
- 详情：原生顶栏（返回、创意名、更多：重新加载/重命名/删除）+ 全屏 WebView；页面有内部历史时返回先回退页面；损坏/缺失显示错误页，可重试；详情页只读，不在页面内驱动 Agent。
- 修改：退出创意回到聊天，用对话让 Agent 改。界面/交互变化由 Agent 编辑页面文件；只改内容/数据（如日报）时 Agent 用 `workshop_data_*` 直接更新数据，不重写页面。
- 聊天入口卡片：`workshop_load` 成功后，assistant 回复下方出现全宽卡片（emoji + 名称 + 「已创建」+ chevron），点击直接打开详情；重新打开历史会话仍可看到卡片。
- 强制加载技能：`/skill:<name> [需求]` 在发送前把技能文件内容读入本轮上下文，聊天里只显示用户文字，不显示技能标记或原始 XML。
- 主题：App 把当前主题色注入页面 CSS 变量（`--dd-bg/--dd-ink/--dd-ink-secondary/--dd-accent/--dd-hairline` + `color-scheme`），切换主题时同步更新；页面深色/浅色由页面自身使用这些变量决定。
- 文案中英双语；视觉沿用现有发丝线/留白/纯文字操作，不新增卡片阴影。

## 通知

- 运行中：前台服务常驻通知显示会话标题与当前活动（思考 / 运行工具 / 重试 / 压缩上下文）；多会话显示数量；通知带「停止」。

- 开发包安装：独立进度通知（更新软件源 / 安装 n/m / 完成 / 失败），不干扰会话通知。
- 设置里的「通知」行显示系统通知权限状态，点击打开系统通知设置。


## 性能

- `app/compose-stability.conf` 把 runtime 模型、`ChatUiState`、`AttachmentRef`、`File` 标记为 stable；全量编译报告显示 ChatScreen 等热路径已无不稳定参数（剩余仅 ViewModel 内部 dispatcher）。
- IME 底部 inset 动画值与抽屉遮罩 alpha 都改到 layout/draw phase 读取，键盘/抽屉动画期间不再逐帧重组整个聊天页或根节点。
- 流式输出在 `ChatViewModel` 内按 16ms 合并 `TextDelta`/`ReasoningDelta`，非 delta 事件、结束、切换、缓存前强制 flush，保证文本与工具顺序及最终文本不丢。
- 按压 wash 的动画值只在 draw phase 读取（`DdPressable`）；图片淡入 alpha 只在 graphicsLayer 读取；Markdown inline span 与高亮结果按文本 remember。
- 流式 Markdown 解析保持 O(n)；`ChatMarkdown` 的解析区间用 `deepdeep.markdown.parse` Trace 标记，可用 Perfetto 观察。

## 导航与动效

- 设置层级（个性化、字体、聊天设置、隐私、厂商列表/详情、运行环境、MCP、插件、技能、定时任务）使用 `AnimatedScreenHost`：聊天页常驻底层，其它页面作为全屏覆盖层右侧 18% 推入 + 淡入，返回反向；系统返回手势触发 pop。返回聊天时直接露出已存在的聊天页，不重建消息列表。

- 页面切换不用于会话切换——会话切换只替换内容和短 loading。
