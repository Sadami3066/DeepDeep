# 命令

聊天输入框支持 `/` 命令。App 命令在本地执行，不发送给模型；`/skill:` 技能命令会把技能正文作为本轮用户消息发出（命令文本本身不进入会话）。需要反馈的结果（如压缩）以消息流里的灰字提示呈现。

## 使用

- 在输入中的任意词边界输入 `/`（行首，或空格/换行后的第一个字符）会展开命令面板；面板可滚动，命令变多时不会挡住消息。
- 点选面板条目只会把完整命令**补全到输入框**，不会立即执行；补全的命令以主题强调色显示。补全参数后按发送才执行。
- 面板顺序固定：App 命令（`/compact`、`/goal`）在上，已启用的技能（`/skill:<name>`）在下面；可按名称、标题或说明过滤。
- 发送时只有整行是一个命令才会执行；未知命令不发送，输入框上方显示提示。
- 以 `/` 开头的普通文本不会被当成命令；前导空格可发送普通文本。

| 命令 | 参数 | 行为 |
|---|---|---|
| `/compact` | 无（后面的文字会被忽略） | 立即压缩较早的历史，显示压缩前后 token 数；运行中、无可压缩历史时有对应提示 |
| `/goal` | `<目标文本>`、`pause`、`resume`、`clear` | `<目标文本>` 直接创建该目标（无弹窗）；pause/resume/clear 直接操作当前目标；空参数提示目标不能为空 |
| `/skill:<name>` | `[需求]` | 强制加载任意已启用技能（全局或当前工作区）；技能内容以 `<skill>` 块进入本轮，未知/未启用技能提示「未找到技能」并保留输入 |

## 技能

- 已启用的技能会自动出现在命令面板的 App 命令下方，点选补全为 `/skill:<name> `；已停用的技能不显示，手动输入会提示未找到。
- 内置 `workshop` 技能就是普通已启用技能，面板里和别的技能一样显示为 `/skill:workshop`；没有专用别名。
- 技能正文在发送时读取当前文件内容，修改技能后无需重启会话；聊天气泡只显示你的需求文字，不显示技能标记或原始 `<skill>` 块。

## 说明

- 命令面板只服务于人；模型侧的能力仍然通过工具调用（`get_goal`/`update_goal`、`job_start`/`job_output`/`job_list`/`job_kill` 等）完成。
- 压缩由 SDK 执行，自动压缩仍按上下文阈值触发；`/compact` 只是手动入口，不接受压缩指导文字。
- 目标续跑会在消息流里留下目标轮提示并开启新的一轮；后台任务唤醒会开启新的一轮，只在回复上方留一行极简任务标记，不显示完成/失败卡片。
