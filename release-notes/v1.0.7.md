## DeepDeep 1.0.7

这次更新集中在界面手感与聊天阅读体验：sheet 不再抽搐，插件卡片按发生顺序出现在对话里，邮箱可以舒服地读图和滑动处理。

### 聊天与插件卡片

- 插件卡片（例如邮箱搜索结果、草稿）、交付卡、小程序卡和提问卡会在它们发生的那个位置出现，不再堆在整段回答的最下面，也不会被之后的文字和工具推着走。
- 思考与工具调用收进可折叠的过程行：流式时自动展开，结束后收起，点一下可以展开回看。
- 重开会话后顺序与当时一致。

### 界面

- 底部弹层统一重写：从任意位置向下拖动即可关闭，遮罩、动画和返回行为一致；修复了内容很高时在顶部继续上滑会抖动的问题，弹层也不会再顶到状态栏。
- 键盘弹出时弹层自动让位，表单输入不再被遮住。
- 页面切换有轻微视差与压暗；列表增删有动效；首屏加载超过一秒才显示占位；空状态与出错状态分开。
- 去掉了一批解释性小字，必要说明改为行尾 info 提示；危险操作仍然保留后果提示。
- 发送消息、切换标签、确认破坏性操作与滑动操作有轻微触感反馈。

### 邮箱插件 1.3.0

- 会话改为整页阅读：顶部返回、归档、删除和更多，底部回复/全部回复/转发，最新一封默认展开。
- 正文按 HTML 渲染，支持内嵌图片、远程图片与 base64 图片，点击可放大查看；附件列表不再混入正文图片。
- 收件箱滑动操作重做：同时只展开一行，松手后自动收起或展开，不再卡在半开状态；归档/删除后仍可撤销。
- 需要 DeepDeep 1.0.7 及以上。

### 插件与 SDK

- 发布 design 0.8.0：新的弹层、滑动行、带图片的 HTML、info 提示与减少动态效果开关。
- plugin-api 保持 1.1.0 / API level 6，已有插件无需重新编译。
- 市场里已安装版本比市场更新时，不再显示「更新」。
