# DeepDeep 1.3.0

这一版让插件把上游服务的完整结果交给模型，并让回答区卡片真正装得下这些内容。

## 完整信息

- 每个插件工具的结果都附带完整的上游返回，模型能看到服务返回的全部字段，不再只看到整理后的一小段。
- 列表不再按 UI 行数截断：飞书消息、企业微信文档、课程、酒店房型、车次、车型、笔记、邮件等一次性返回当前查询的全部条目。
- 上游还有更多数据时，结果里会给出继续翻页的参数，而不是一句“还有 N 条未显示”。
- 错误保留服务端原文与可操作建议；只有登录票据一类的凭据会被隐去，并明确说明。
- 命令行输出超过单次上限时，优先从完整日志恢复；恢复不了会明确提示缩小范围，不会假装结果完整。

## 卡片

- 卡片承载当前查询的全部内容：默认先给预览，展开后能看到每一行；课表、场馆时段等用横向滑动或分页切换。
- 卡片里能看到更细的字段：高德地点带电话、评分、商圈与照片；酒店房型带全部价格方案与取消政策；车次带全部席别状态；邮件读到完整信纸与附件。
- 飞书会话显示真实头像；邮箱新增已发送。

## 卡片交付

- 工具结果会告诉模型“有一张可用卡片”以及它是什么；模型据此用 `present` 决定交付哪几张，一次可以交付多张。
- 模型不再需要自己在正文里复述卡片内容；正文写结论与下一步。

## 各省份服务

- 中山大学：统一登录会自动把教务、在线教学、场馆、网费四个站点都登录好；某个站点会话失效时，助手会先用已保存的凭据重新登录，而不是让你再去插件页操作。
- 酒店：订单列表带完整字段；单笔订单可以查看酒店确认号、入住人、支付截止、免费取消截止等信息。
- 12306：全部车次与全部席别状态（可售、无票、未开售）。
