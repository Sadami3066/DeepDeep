## DeepDeep 1.0.6

本次更新把插件能力扩展到系统、设备与数据层，并完善插件更新、通知与稳定性。

### 插件

- 插件 API 升级到 1.1.0（API level 6，纯加法）：已安装的插件无需更新即可继续使用。
- 新增一批插件能力：设备状态、剪贴板、权限申请、应用管理、Root 与无线调试、系统 Intent、独立窗口、后台周期任务与开机唤醒、定位、联系人、短信、日历、媒体保存、语音、网页搜索、宿主凭据、无障碍事件、插件设置存储、分享接收与深链。
- 插件可以使用宿主通知监听与通知动作、页面参数、确认/输入/选择/日期时间/文件/图片/扫码等交互组件，以及新的界面组件（Markdown、WebView、图片查看、HTML 文本、下拉刷新、文件行）。
- 安装插件时会展示它申请的权限与系统组件；通知监听、无障碍等系统级授权仍需你在系统设置里确认。
- 插件更新改为手动：在插件详情点「立即更新」后才生效，不再自动应用。
- 插件未捕获的异常不再带崩 App，而是记录日志并把该插件标记为失败。
- 进入 MCP 页面时自动刷新服务器状态。
- 官方插件同批更新：邮箱 1.2.0（写信附件、后台定时同步、通知动作、页面参数），飞书 / 企业微信 / 中山大学 / 小米云服务 2.1.0，微信导出 0.4.0。

### 设置

- 设置 → 关于 新增「崩溃记录」：可查看、复制、分享与清除最近的崩溃日志，方便反馈问题。
